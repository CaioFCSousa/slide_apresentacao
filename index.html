Algoritmo = passos claros que qualquer pessoa (ou máquina) segue sem precisar pensar.

1928

O matemático David Hilbert pergunta: existe uma receita mecânica que responda qualquer pergunta da lógica?

1936

Alonzo Church e Alan Turing respondem: não existe. Para provar, precisaram definir exatamente o que é uma "receita".

    O que ele não consegue garantir
    Perguntas sobre o que o código faz
    
    
    
      
    ?Esse loop termina?
    É o próprio Problema da Parada.
    
      
    ?Esse trecho vai rodar algum dia?
    O código depois de um loop só roda se o loop terminar. É o Problema da Parada disfarçado.
    while (condicao) { … }print("chegou aqui?")
    
      
    ?A variável sempre recebe valor antes de ser usada?
    Depende de qual caminho o programa vai seguir quando rodar.
    
      
    ?Esse é o código mais rápido possível?
    Para saber, teria que entender tudo o que o programa faz.
    
    
    
    
    Se o compilador respondesse isso sempre, ele resolveria o Problema da Parada. Por isso, não consegue.
